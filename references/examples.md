# 場面別 実例文面

過去1年（2025/07〜2026/07）の実際の送信メールから抽出した骨格。固有名詞・案件内容は伏せ字または一般化してある。近い場面があればこの型を借りる。

---

## 1. 依頼（背景説明つき・こちらの都合でお願いする）

いちばん頻度が高い型。**背景 → 影響 → お願い → 資料 → 補足 → 恐縮つきの締め**。

```
佐原さま

ご無沙汰しております。
Karappoの寺田です。

本日は、現在下記のページで使用している「Google Maps」についてご相談とお願いがありご連絡いたしました。
https://example.com/company/

現在、マップの表示に必要な「ライセンス・キー」は弊社のものを使用しております。
以前は無料枠が大きく問題なかったのですが、昨年料金体系の変更があり、
弊社の全てのキー（他のお客様分も含む）の使用量の合計が基準を超えると弊社へ請求が届く状況になってしまいました。

つきましては、今後の継続運用のために、大変お手数ですが、
キーの切り替えに必要な作業をお願いしたく存じます。

詳しくは下記資料のご確認をお願いいたします。

▼ Google Maps 継続利用のためのお願い
https://docs.google.com/document/d/xxxx

▼ 補足
〇〇ウェブの過去１年間のマップ表示数を確認すると、一番多い月で1,000回程度で、無料枠内に十分に収まっています。

お手数をおかけして大変恐縮ですが、ご協力のほど何卒よろしくお願いいたします。

寺田
```

ポイント
- 「本日は、〜についてご相談とお願いがありご連絡いたしました。」で切り出す
- 「以前は〜だったのですが、〜変更があり、〜状況になってしまいました」で、**こちらの都合ではなく外部要因であること**を示す
- 「▼」で資料と補足を分ける
- 補足で「無料枠内に十分に収まっています」＝相手の不安（お金がかかるのでは）を先に潰す

## 2. 手順つき依頼（見積添付・作業をお願いする）

```
朝比奈様

ご無沙汰しております。
Karappoの寺田です。

本日は、御社ウェブサイト（example.jp）で使用しているウェブフォントサービスについて、ご相談がありご連絡いたしました。

現在、〇〇様のウェブサイトでは、株式会社モリサワのウェブフォントサービス「TypeSquare」を利用しておりますが、このたびモリサワ側でのサービス体系変更に伴い、後継サービス「Morisawa Fonts」への移行が案内されております。
https://www.morisawa.co.jp/about/news/xxxxx

そのため、今後も現在の表示を維持するためには、サイト側でも移行対応を行う必要がございます。
つきましては、移行作業に関するお見積書を添付いたしますので、まずは内容をご確認いただけますでしょうか。
モリサワからの案内では、2027年11月30日が更新受付の最終日とされており、期限までにはまだ余裕がございます。
一方で、いずれ対応が必要になる内容のため、可能であれば余裕を持って早めに進められますと安心かと考えております。
実施時期についてご希望がございましたら、もちろん調整可能ですので、お知らせください。

ご発注いただける場合は、まず、
大変お手数ですが「アカウントの作成と共有」をお願いしたいと考えております。

具体的な背景と手順は以下の通りです。

（1）Morisawa Fonts 公式ページにアクセス
https://morisawafonts.com/plans/webfont/
※ご契約いただきたいプランは「**Webフォント Lite**」になります。
（金額はご利用中のTypeSquareのプランと同額です）

（2）アカウント（Masiro ID）作成とプラン申し込み
画面の指示に従い会員登録を進め、プランの契約をお願いいたします。
※年間契約と月契約が選べますが、年契約でも割安にならないようなので、
**月契約**をお勧めします。どちらの場合も**「自動更新」になっているかは必ずご確認をお願いします**。

（3）アカウントの共有
実装作業のため「管理者」以上の権限が必要になりますので、
下記のいずれかをお願いします。
A. オーナー（プラン契約者）のログイン情報をそのまま共有いただく（クレジットカード情報は管理画面上で伏せられるので、問題はないかと思います）
B. 「管理者」として info@karappo.co.jp を招待していただく

ここまでがお願いしたい作業になります。

なお、どうしてもTypeSquareとMorisawa Fontsを重複して契約する期間が発生します。
共有いただいたアカウントを使って実装作業を行い、
移行完了後、改めてTypeSquareの解約手続きをお願いするのですが、
そこまでが今月中に収まると重複期間を最小限に抑えやすくなるかと存じます。
今月お忙しそうであれば、調整可能ですのでその旨お知らせいただければ幸いです。

ご不明な点や、手順がうまくいかない場合は、いつでもお気軽にご相談ください。
突然のご相談となり恐縮ですが、どうぞよろしくお願いいたします。

寺田
```

ポイント
- 「（1）（2）（3）」で手順、選択肢は「A. B.」
- 「※」で注意点、太字で読み違えてほしくない箇所を潰す
- 「ここまでがお願いしたい作業になります。」で依頼範囲を明示して区切る
- 期限に余裕がある／調整可能／困ったら相談してよい、を3点セットで置く

## 3. 報告（電話・依頼を受けての対応完了報告）

```
山形さま

お世話になっております。
Karappo寺田です。

先ほどお電話いただいたサーチコンソールの件で、ご報告です。

サーチコンソールの管理者に、山形さまを yamagata@example.jp で追加いたしました。
案内の、メールが届いているのではないかと思います。

もし届いていない場合も、ログインしている状態で下記にアクセスするとみられるはずです。
https://search.google.com/search-console/

こちらからすでに作業済みなので、今後のためですが、
「インデックス登録のリクエスト」はこちらのページの「インデックス登録をリクエスト」から行えます。（添付画像参照）
https://search.google.com/search-console/inspect?resource_id=xxxx

ご確認をよろしくお願いいたします。

寺田
```

ポイント
- 「〜の件で、ご報告です。」で入る
- 「もし届いていない場合も〜」＝相手がつまずくパターンを先に潰す
- 「こちらからすでに作業済みなので、今後のためですが」＝今すぐの作業は不要であることを明示

## 4. 不具合報告＋原因がわからないときの謝罪

```
田山様

お世話になっております。

先ほどご連絡いただいた１０月の消費予報のリンク先がNotFoundと表示されていた件、
当該記事のスラッグを「2025-10」に変更することで一旦治りました。
（添付画像）

ただ、スラッグの設定はしなくてもパーマリンク設定のみで本来はうまくいくはず（他の記事は動作している）なので、
原因ははっきりとわかりませんでした。
申し訳ありません。

弊社の他のメンバーにも確認したところ、本番の方は触っていないということで、
こちらの作業の影響ではないようです。

数日前に本番のデータをステージングに転送したのですが、
その時点のデータステージング上ではこの不具合は見られず、
あらためて現在の本番のデータをローカルに転送すると不具合が発生しました。
このことから、ここ数日間の管理画面上での操作の影響かと推測されるのですが、
同じパーマリンクを設定しようとするとエラーになるはずなので、
具体的にどの操作が引き金になったかまでは特定が難しい状況でした。

ご確認の程、よろしくお願いいたします。

寺田
```

ポイント
- **まず「治った」を書く**。原因の話は後
- わからないことは「原因ははっきりとわかりませんでした。申し訳ありません。」と正直に書く
- 事実（確認したこと）と推測（「〜かと推測されるのですが」）を分ける
- 相手のせいに読める内容（管理画面の操作）でも、断定せず特定できなかったと書いて終える

## 5. 自社の不備を謝罪して対応方針を相談する（長文の整理法）

```
京葉事務所　北口さま
（坂本会計 藤堂さま、Karappo三尾）

お世話になっております。
Karappoの寺田です。

弊社従業員の〇〇について、昨年度の有休日数を誤っていたため、
一部「欠勤」扱いにしてしまっていた点があり、
精算方法について確認させていただけないでしょうか。

＜誤って欠勤としていた日（計5日）＞
7/29、11/11~14

＜経緯＞
2025年5月に〇〇が入社しました。
7月（年度はじめ）になり全社的に有給一斉付与を行ったのですが、
その時に、ふと働き始めたばかりの〇〇にも付与するのかと疑問に思い、調べたところ、
『入社後6ヶ月間、全労働日の8割以上出勤の条件を満たすと10日付与される』という法律のことを知りました。（※1）
（…中略…）

※1 〇〇入社の前は、有給管理ツールが異なっていたこともあり、こういう疑問自体を持つことがない状況でした

＜対応策＞
賃金：
上記の期間に欠勤扱いだった5日分を来月（8月）支給分の給与に上乗せする形で精算。

勤怠や有休日数：
2025/7/1付で13日分を付与、（…中略…）
つまり、13日 - 4日（夏季） - 5日（冬季） - 1日（6/19 ※3） = 3日残る計算です。

※2 年次有給は0にしていましたが、夏季冬季休業については特別有給休暇としていました。
※3 今回の問題発覚のきっかけとなった6/19の有給申請分です。

上記のような内容で、本人にも確認をとった上で、対応をしようと考えております。
不足の点などがもしありましたら、ご教授いただけるとありがたいです。

お手数をおかけしてしまい大変申し訳ありません。
ご確認のほど、何卒よろしくお願いいたします。

寺田
```

ポイント
- 「＜経緯＞＜対応策＞」の山括弧見出しで長文を整理し、細かい補足は「※1」「※2」に逃がす
- 経緯は自分がどう誤解したかまで書く（言い訳ではなく事実として）
- 「対応策」まで自分で用意してから相談する
- 締めの直前に謝罪、最後に確認依頼

## 6. 催促（返信・作業が止まっているとき）

```
佐藤さま

お世話になっております。
ご対応ありがとうございます。

最後にお手数をおかけして申し訳ないのですが、
「プロジェクトID」の共有を、お願いできませんでしょうか。
プロジェクトIDをコピペしてメールに貼り付けていただくか、
下記のようなスクショでも構いません。

> 5. プロジェクトIDの共有

何卒よろしくお願いいたします。

寺田
```

ポイント
- **先にお礼**（すでに対応してもらった分）
- 「最後に」で残り1件だけと伝える
- 何が欲しいかを具体化し、**やり方の選択肢を出す**（コピペ／スクショ）
- 元の依頼を `>` で引用して照合しやすくする
- 相手の遅れには一切触れない

## 7. お断り（引き合いを辞退する）

```
田中さま

ご無沙汰しております！
また、お返事が遅くなり申し訳ありませんでした…。

この度はお仕事のご相談ありがとうございます。
ただ、大変申し訳ないのですが、
弊社の方で Studio に特化した体制や知見が十分でなく、
品質やスピード感でご期待に沿うことが難しそうに思いました。
せっかくお声がけいただいたところ、ご期待に沿えず大変心苦しいのですが、
ご了承いただけますと幸いです。大変申し訳ありません。

今後も何かあればお気軽にご相談いただけるとありがたいです。
何卒よろしくお願いいたします。

寺田
```

ポイント
- 断る理由は**自社の体制・知見**に置く（相手の案件を否定しない）
- 「難しそうに思いました」と柔らかく言い切る
- 「今後も何かあればお気軽にご相談いただけるとありがたいです。」で関係を残す

## 10. 作業依頼（相手に手を動かしてもらう・急がない）

```
宮下さま、正分さま

いつもお世話になっております。
Karappo寺田です。

実は、以前も作業をお願いした「〇〇」（https://example.jp/xxx/）について、
また不具合が発生していることがわかり、ご対応のお願いです。

原因と対応：
点群データの最新情報を外部から取得する部分があり、そちらの仕様変更が原因でした。
このデータは本サイト（https://example.org/）でも参照しているため、
今後２つのサイト用にメンテしていくのが困難と判断し、依存関係を切ったバージョンを作成しました。
こちらで置き換えていただけますでしょうか。
これで文字通り「アーカイヴ」ができるようになったかと思います。

https://www.dropbox.com/scl/fi/xxxx/niwa.zip

たびたび、お手数をおかけして大変申し訳ありません。
急ぎませんので、お手すきの際にご対応いただければ幸いです。

どうぞよろしくお願いいたします。

寺田
```

ポイント
- 「実は、」で言い出しにくい再依頼を切り出す
- 「原因と対応：」の一行見出しで技術的な説明をひとまとめ
- 「これで文字通り『アーカイヴ』ができるようになったかと思います。」＝依頼のついでに、相手にとっての良い面を一言添える
- 「たびたび〜申し訳ありません」＋「急ぎませんので、お手すきの際に」の2点セット

## 11. 親しい相手への技術相談への回答（A トーン・口語）

```
長沼さん

ご無沙汰しています！

花粉症であまり元気ではないですが、元気です！

メールの件、ムームードメインにメールサービスがあり
こちらから進めるのが一番手軽かと思います。
https://muumuu-domain.com/email/muumuu-mail

ちなみにですが、メール送受信にはメールサーバーが必要なのでドメインだけあっても全くの無料で使うことはできません。

他に、お金をしっかりかけても良いのであれば、
aidaho.jp と同じように、Google Workspace にする方法もあります。
一番使いやすいと思いますが、手続きも複雑になります。

ムームーメールにして、他のアドレスに転送するようにしておけば受信に気づくし良いんじゃないかな？と思いました。

細かい案内までは、できかねるのですが、
どうしても困ったらまた声をかけてください！

寺田
```

ポイント
- 相手の雑談（「元気ですか？」）に一言乗る
- 選択肢を「手軽な方」→「お金をかける方」の順で出し、それぞれのトレードオフを一言
- 「〜良いんじゃないかな？と思いました」まで崩す
- 「細かい案内までは、できかねるのですが」＝**無償対応の範囲をやわらかく線引き**しつつ、突き放さない
